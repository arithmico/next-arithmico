# Headless Components

This package provides accessible components for the Yew frontend framework.

## Development

To start developing with these components, you need to set up a Yew project.

## Installation

Add the headless_components package to your `Cargo.toml`:
```toml
[dependencies]
headless_components = { path = "./relative/path/to/this/package" }
```

## Accessibility

All components in this package are designed with accessibility in mind, ensuring that your applications are usable by as many people as possible.
